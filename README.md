# Métro Express

Métro Express is a static daily Paris transit route puzzle game. A fresh clone or static deployment works immediately: the app loads a committed shared network file and a small committed daily puzzle file.

## Data Source

Data is generated deterministically from the local `gouv_paris_gtfs-export/` GTFS snapshot. It is not generated by an LLM, and no station pairs are invented.

The current generated files are based on the ITO World modified GTFS export derived from Île-de-France Mobilités:

- version: `20260630_200738`
- valid from: `2026-06-27`
- valid to: `2026-07-29`

Generated puzzles are based on this snapshot only. They do not reflect live schedules, closures, disruptions, or real-time service changes.

## Route Model

`scripts/build_data.py` filters the GTFS export as follows:

- `route_type=0`: tram-like routes; keep labels beginning with `T`, excluding airport people movers such as `ORLYVAL` and `CDG VAL`
- `route_type=1`: metro; keep all
- `route_type=2`: rail; keep only RER `A`, `B`, `C`, `D`, and `E`
- `route_type=3`: bus; excluded for v1
- `route_type=6` / `7`: excluded for v1

Puzzle endpoints are metro-served stations plus RER stations within central Paris bounds. The route graph still uses the full selected metro/RER/tram network for route legs.

Candidate pairs are ordered: `A -> B` and `B -> A` are distinct because fastest paths, waits, branches, directions, and transfers can differ by direction. Pairs with the same station name at both ends are skipped. Routable candidates include a full precomputed `optimalRoute`; unroutable candidates are included in the local all-pairs export with `routable: false`.

Playable pairs must have:

- a valid fastest route
- endpoint distance at least 1.5 km
- route distance at least 1 km
- more than 3 transit edges
- at least 1 transfer

Non-playable candidates are retained in the local exhaustive export with reason codes.

## Data Layout

Committed:

- `public/data/metro-express-network.json`: shared static route, station, transfer, direction, and wait metadata
- `public/data/daily/YYYY-MM-DD.json`: small daily puzzle files, 5 playable puzzles per day
- `public/data/daily/index.json`: small static index used to find today or the nearest committed daily file
- `public/data/example/metro-express-example-data.json`: clearly marked 100-pair example/dev dataset
- `scripts/build_data.py`

Ignored:

- `gouv_paris_gtfs-export/`: local GTFS source snapshot
- `public/data/generated/metro-express-all-pairs.json`: exhaustive ordered candidate export
- `public/data/metro-express-data.json`: legacy generated single bundle
- `scripts/__pycache__/` and `*.pyc`

The frontend does not load the exhaustive all-pairs file.

## Regenerate Data

Use the bundled Python runtime already cached by Codex:

```powershell
& 'C:\Users\iddo2\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts\build_data.py --mode network
```

Generate the ignored exhaustive ordered candidate export:

```powershell
& 'C:\Users\iddo2\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts\build_data.py --mode all-pairs
```

Generate the committed 100-pair example/dev dataset:

```powershell
& 'C:\Users\iddo2\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts\build_data.py --mode example --count 100
```

Generate one year of committed daily files, 5 puzzles per day, starting on `2026-07-28`:

```powershell
& 'C:\Users\iddo2\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts\build_data.py --mode daily-range --start-date 2026-07-28 --days 365 --count 5
```

For a release refresh, run everything in one pass:

```powershell
& 'C:\Users\iddo2\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts\build_data.py --mode release --start-date 2026-07-28 --days 365 --daily-count 5 --example-count 100
```

`example` and `daily-range` modes reuse `public/data/generated/metro-express-all-pairs.json` when it already exists.

## Play Locally

```powershell
cd public
& 'C:\Users\iddo2\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 4173
```

Open `http://127.0.0.1:4173`.

The app first loads `public/data/metro-express-network.json`, then today’s daily file. If today is not committed, it uses `public/data/daily/index.json` to load the nearest available daily file. If daily files are unavailable, it falls back to the committed example/dev dataset.
