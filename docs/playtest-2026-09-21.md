## Confirmed issue: Chicago Brown Line direction is misleading

Severity: P2 (route-choice guidance).

Reproduction:

1. Open Chicago, Easy, 2026-09-21, puzzle 4: Kedzie → Lake.
2. Select Brown.
3. The only direction shown is **Kimball**.
4. Select it. The stop list begins with Belmont (15 mins), Wellington (17 mins), Diversey (18 mins), Fullerton (20 mins), then continues toward downtown.

These are the Loop-bound stops from Kedzie, although the direction label says Kimball. An unfamiliar player is given misleading direction guidance. Selecting Belmont and transferring to Red toward 95th/Dan Ryan still reaches Lake correctly: 100 points, 38 mins 3s.

Local source trace: `scripts/sources/chicago.py:22` uses one headsign/terminal label for a direction. The `Brn:0` direction in `public/data/chicago/network.json` is labeled Kimball and contains a complete Kimball → Loop → Kimball pattern. `public/app.js:2834` takes that fixed label when creating the direction choices. A position-aware direction label, distinguishing travel toward the Loop from travel toward Kimball, would address the observed guidance problem. No fix was made during this playtest.
