FAQ

Which lines are included?

The game includes the Metro, RER A to E, and the T1 to T14 tram lines. It leaves out buses, ORLYVAL, and CDG VAL.

Why is the fastest route different from the one I know?

Chronométro follows its own static route map and timing model. Ride times come from timetable data. Waits and transfers are estimates. Direction and branches also matter, so the return trip may have a different answer.

How does it find the fastest route?

The game treats stations and connections as a weighted graph, then uses Dijkstra's algorithm to find the route with the lowest total time. This Veritasium video explains the basic idea.

When is walking an option?

The source transit data lists walking connections between some stations. The game offers a walk only when one of those links exists, or when two records refer to the same station.

How are waiting times estimated?

The game looks at scheduled departures from 7:00-10:00 AM, finds the median gap between services, and uses half of that as the expected wait. The idea is that you arrive halfway between the previous and next train. When there is not enough data for a direction, it falls back to the line and then the transport mode.

The model adds a wait for the first service you board. It does not add time for entering the departure station or walking to the first platform. It does count a walking transfer if you start by moving to another linked station.

Does the site save anything?

There are no accounts or cookies, and the game does not use local storage. Your route and scores disappear when you reload or close the page.
